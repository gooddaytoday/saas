# `app/components` Directory

This directory contains all the React components used in the Next.js application, organized by feature or domain.

### Structure

- **`common/`**: Contains a set of reusable, general-purpose React components that are used throughout the application. See the `README.md` in that directory for more details.
- **`discussions/`**: Contains components related to the discussion feature, such as forms for creating and editing discussions, and lists of discussions.
- **`layout/`**: Contains the main layout component for the application, which likely includes the header, footer, and navigation.
- **`posts/`**: Contains components for displaying and interacting with posts within a discussion, such as the post content, editor, and detail view.
- **`teams/`**: Contains components related to team management, such as inviting new members.

### Important Notes

- The component-based architecture allows for a clean separation of concerns and promotes reusability.
- The directory structure makes it easy to find components related to a specific feature.
