# `app` Directory (Client-side Application)

This directory contains the entire client-side application, which is built using Next.js, React, Material-UI, and MobX.

### Structure

- **`components/`**: Contains all the React components, organized by feature. See the `README.md` in that directory for more details.
- **`lib/`**: Contains a collection of modules that provide various functionalities for the client-side application, including API communication, state management, and utility functions. See the `README.md` in that directory for more details.
- **`pages/`**: Contains all the pages for the Next.js application. Each file in this directory corresponds to a route in the application. See the `README.md` in that directory for more details.
- **`public/`**: Contains static assets like fonts and images that are publicly accessible.
- **`server/`**: Contains a custom Express server for Next.js. This is used to implement server-side caching and to set up sitemaps and `robots.txt`.
- **`production-server/`**: This directory is likely used for the production build of the custom server.
- **`coverage/`**: Contains code coverage reports generated by Jest.
- **`types/`**: Contains TypeScript type definitions.
- **`jest.config.js`**, **`jest.setup.js`**: Configuration files for the Jest testing framework.
- **`next.config.js`**: The main configuration file for Next.js.
- **`tsconfig.json`**: The main configuration file for TypeScript.

### Important Notes

- **Framework**: The application is built on Next.js, which provides features like server-side rendering, static site generation, and a file-system based router.
- **UI**: The user interface is built using React and the Material-UI component library.
- **State Management**: Client-side state is managed using MobX.
- **Styling**: Styling is done using a combination of Material-UI's styling solution (likely Emotion or JSS) and global CSS.
- **Testing**: The application is tested using Jest and React Testing Library.
